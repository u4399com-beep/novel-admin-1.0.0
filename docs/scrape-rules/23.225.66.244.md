## 内容分页 (Content Pagination)

### 状态: 已启用
该站二三阅读的长章节内容经常跨多页，每页约2000-3000字，通过"下一页"链接连接。

### 配置说明
```json
{
  "contentPagination": {
    "type": "next",
    "selector": "a.next, a:contains(\"下一页\")",
    "maxPage": 10
  }
}
```

### 工作原理
1. 引擎首先抓取章节第一页内容
2. 在当前页面查找 `a.next` 或包含"下一页"文本的链接
3. 如果找到，则跟随链接抓取下一页
4. 重复直到无下一页链接或达到 `maxPage` 限制
5. **每页的HTML会先经过 `cleanHtmlRaw` 清洗**（移除CSS选择器匹配的广告元素、脚本、样式等），再提取文本
6. 所有页面的文本合并后，再经过 `cleanText` 进行行级别广告文本过滤和水印移除
7. 最终得到完整的、清洁的章节正文

### 关键要点
- `contentPagination` 字段控制多页内容的自动合并
- HTML级别清洗通过 `cleanHtmlRaw` 在每页上独立执行，确保广告HTML结构在提取文本前被移除
- `maxPage: 10` 防止极端情况下无限翻页
- 即使有分页，单章节字数通常不超过30000字

## 注意事项

1. **必须使用playwright引擎**：章节内容由JS动态渲染，cheerio无法获取正文
2. **线程数必须为1**：该站反爬较严格，多线程容易触发封禁
3. **延迟建议3000-6000ms**：比普通站更长
4. **contentPagination已启用**：长章节自动跟随"下一页"合并内容
5. 首页推荐列表中有些链接是"新书推荐"而非真实章节，采集时注意过滤
6. 封面图片使用相对路径，需要拼接完整URL: `http://23.225.66.244{path}`
7. 书籍URL格式: `/bqg/{id}/`，章节URL格式: `/bqg/{id}/{chapterId}.html`
8. 有些书籍有"完结感言"等非正文章节，通过cleanConfig的adPatterns过滤
