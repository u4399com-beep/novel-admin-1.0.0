## 选择器说明

### 列表页
- **listSelector**: `article li` — 分类页中每个<li>包含一本书的链接和封面
- **bookTitleSelector**: `a[href*="5165.org/"]` — li中的链接文本即为书名
- **bookCoverSelector**: `a img` — 封面图片在链接内的img标签中

### 书籍详情页
- **chapterListSelector**: `article` — 章节列表在article标签内
- **chapterTitleSelector/LinkSelector**: `a[href$=".html"]` — 章节链接以.html结尾
- 书名和作者从页面Schema.org JSON-LD中提取（title和author字段）
- 描述从og:description meta标签提取

### 章节内容页
- **contentSelector**: `.entry-content` — 内容在entry-content div中，每个段落包裹在`<div data-id="N"><p>...</p></div>`

## 注意事项

1. 首页`<ul class="indexpic">`是推荐位，不是完整列表，应使用分类页作为listUrl
2. 封面URL格式: `https://5165.org/book/uploads/YYYY/MM/{slug}.jpg`
3. 书籍URL格式: `https://5165.org/{category}/{slug}/`
4. 章节URL格式: `https://5165.org/{category}/{slug}/{id}.html`
5. 部分分类有wangluo2/wenxue2等分页，建议使用分页功能采集完整
