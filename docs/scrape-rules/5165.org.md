## 选择器说明

### 列表页 (分类页)
- **listSelector**: `.entry-content li a[href]` — 分类页中所有书籍链接。格式：`<a href="/wangluo/slug/">Title</a> <span class="text-muted">Author</span>`
- **注意**: `article li` 仅包含6本推荐位书籍，**不是完整书单**。完整书单1833+本在 `.entry-content li` 中
- **无分页**: 所有书籍在分类页单页列出，无需listPagination

### 书籍详情页
- **bookTitleSelector**: `h1.entry-title, h1` — 页面标题h1标签
- **bookAuthorSelector**: `.entry-content .text-muted, .author` — 正文区域的作者信息
- **bookDescriptionSelector**: `meta[property='og:description']` — 从og:description元标签提取描述（extract: content属性）
- **bookCoverSelector**: `.entry-content img, article img` — 正文或文章区域的图片
- **bookCategorySelector**: `.entry-meta a, .cat-links a` — 分类标签链接
- **chapterListSelector**: `.entry-content` — 章节列表在entry-content中
- **chapterTitleSelector/LinkSelector**: `a[href$=".html"]` — 章节链接以.html结尾

### 章节内容页
- **contentSelector**: `.entry-content` — 内容在entry-content div中
- **contentTitleSelector**: `h1.entry-title, h1` — 章节标题
- 每个段落包裹在 `<div data-id="N"><p>...</p></div>` 格式中

## 内容分页 (Content Pagination)

### 状态: 不适用
该站5165.org的章节内容通常为单页，不需要内容分页。`contentPagination` 设为 `null`。

如果未来某些章节变为多页结构，可添加以下配置：
```json
{
  "contentPagination": {
    "type": "next",
    "selector": "a.next, a:contains(\"下一页\")",
    "maxPage": 10
  }
}
```

### 工作原理
- `contentPagination` 字段控制章节内容是否跨多页
- 当章节正文较长时，站点可能将其分为多页，通过"下一页"链接连接
- 配置后，引擎会自动跟随"下一页"链接，逐页抓取内容
- 每页的HTML会先经过 `cleanHtmlRaw` 清洗（移除CSS选择器匹配的广告元素），再提取文本
- 所有页面的文本合并后，再经过 `cleanText` 进行行级别广告文本过滤

## 注意事项

1. **必须使用playwright引擎**：Cloudflare WAF保护，cheerio/curl请求会返回挑战页面
2. **线程数必须为1**：Cloudflare保护下多线程极易触发封禁
3. **延迟建议3000-5000ms**：比普通站更长，避免触发Cloudflare rate limit
4. 首页 `<ul class="indexpic">` 是推荐位，不是完整列表，应使用分类页作为listUrl
5. 封面URL格式: `https://5165.org/book/uploads/YYYY/MM/{slug}.jpg`
6. 书籍URL格式: `https://5165.org/{category}/{slug}/`
7. 章节URL格式: `https://5165.org/{category}/{slug}/{id}.html`
8. Schema.org JSON-LD元数据包含结构化的书名、作者、描述信息
